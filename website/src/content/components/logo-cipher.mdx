import {
  AppLogo,
  AnimatedSymbol,
  AnimatedLogo,
} from "@/components/common/icon/cipher/app-logo";

The Cipher brand logo as a React component. Supports horizontal, vertical, symbol-only, and wordmark-only layouts. Includes `AnimatedSymbol` and `AnimatedLogo` components with a split-symbol hover animation.

## Usage

```tsx
import { AppLogo, AnimatedSymbol } from "@/components/common/icon/cipher/app-logo";

<AppLogo />
<AnimatedSymbol />
```

### Animated Symbol

The `AnimatedSymbol` component renders the left and right halves of the symbol as separate elements, allowing them to be animated independently via `leftClassName` and `rightClassName`.

<ExampleContainer>
  <div className="flex items-center gap-8">

    <AnimatedSymbol height={64} colored />
  </div>
</ExampleContainer>

```tsx

```

### Animated Symbol with Hover

## Components

### AppLogo

Renders the Cipher brand logo in one of four layout variants.

| Prop        | Type                                                   | Default        | Description                            |
| ----------- | ------------------------------------------------------ | -------------- | -------------------------------------- |
| `variant`   | `"horizontal" \| "vertical" \| "symbol" \| "wordmark"` | `"horizontal"` | Layout variant                         |
| `height`    | `number`                                               | `32`           | Height in pixels                       |
| `colored`   | `boolean`                                              | `false`        | Apply primary color to the symbol mark |
| `className` | `string`                                               | —              | Additional CSS classes                 |

### AnimatedSymbol

Renders the symbol as two independently animatable halves (left and right). The gap between halves scales proportionally — 4px at height 80.

| Prop        | Type      | Default | Description                             |
| ----------- | --------- | ------- | --------------------------------------- |
| `height`    | `number`  | `80`    | Height in pixels                        |
| `colored`   | `boolean` | `false` | Apply primary color to the symbol       |
| `className` | `string`  | —       | Additional CSS classes on the container |

### AnimatedLogo

Horizontal layout combining the animated split-symbol with the wordmark. Hover triggers the symbol animation.

| Prop        | Type      | Default | Description                             |
| ----------- | --------- | ------- | --------------------------------------- |
| `height`    | `number`  | `32`    | Height in pixels                        |
| `colored`   | `boolean` | `false` | Apply primary color to the symbol       |
| `className` | `string`  | —       | Additional CSS classes on the container |
