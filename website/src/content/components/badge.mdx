import { Badge } from "@/components/ui/badge";

A small label for categorization, status indicators, or counts. Supports semantic color variants and three sizes. Renders as a `<span>` by default but can be rendered as a button or link via the `render` prop.

## Usage

```tsx
import { Badge } from "@/components/ui/badge";

<Badge>Label</Badge>;
```

## Components

### Badge

Renders as a `<span>` by default. Use the `render` prop to change the element (e.g., `<a>` or `<button>`), which automatically applies interactive styles like hover and touch targets.

| Prop        | Type                                                                                        | Default     | Description                          |
| ----------- | ------------------------------------------------------------------------------------------- | ----------- | ------------------------------------ |
| `variant`   | `"default" \| "primaryMuted" \| "secondary" \| "outline" \| "destructive" \| "error" \| "warning" \| "success" \| "info" \| "red" \| "orange" \| "amber" \| "yellow" \| "lime" \| "green" \| "emerald" \| "teal" \| "cyan" \| "sky" \| "blue" \| "indigo" \| "violet" \| "purple" \| "fuchsia" \| "pink" \| "rose"` | `"default"` | Color variant               |
| `size`      | `"sm" \| "default" \| "lg"`                                                                 | `"default"` | Badge size                           |
| `render`    | `ReactElement`                                                                               | —           | Custom element to render as          |
| `className` | `string`                                                                                     | —           | Additional CSS classes               |
| `children`  | `ReactNode`                                                                                  | —           | Badge content                        |
