import { Avatar, AvatarImage, AvatarFallback } from "@/components/ui/avatar";

A circular image element for representing users or entities, with an automatic text fallback when the image is unavailable. Built on [Base UI Avatar](https://base-ui.com/react/components/avatar).

## Usage

```tsx
import { Avatar, AvatarImage, AvatarFallback } from "@/components/ui/avatar";

<Avatar>
  <AvatarImage src="/avatar.jpg" alt="User" />
  <AvatarFallback>JD</AvatarFallback>
</Avatar>;
```

## Components

### Avatar

The root container. Renders a circular wrapper with overflow hidden.

| Prop        | Type        | Default | Description            |
| ----------- | ----------- | ------- | ---------------------- |
| `children`  | `ReactNode` | —       | Image and fallback     |
| `className` | `string`    | —       | Additional CSS classes |

### AvatarImage

The user image. Automatically hidden if the `src` fails to load.

| Prop        | Type     | Default | Description            |
| ----------- | -------- | ------- | ---------------------- |
| `src`       | `string` | —       | Image URL              |
| `alt`       | `string` | —       | Accessible alt text    |
| `className` | `string` | —       | Additional CSS classes |

### AvatarFallback

Displayed when no image is available or while the image is loading. Typically shows initials.

| Prop        | Type        | Default | Description            |
| ----------- | ----------- | ------- | ---------------------- |
| `children`  | `ReactNode` | —       | Fallback content       |
| `className` | `string`    | —       | Additional CSS classes |
