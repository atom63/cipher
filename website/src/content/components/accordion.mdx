import {
  Accordion,
  AccordionItem,
  AccordionTrigger,
  AccordionContent,
} from "@/components/ui/accordion";

A vertically stacked set of interactive headings that reveal or hide associated content. Built on [Base UI Accordion](https://base-ui.com/react/components/accordion).

## Usage

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionTrigger,
  AccordionContent,
} from "@/components/ui/accordion";

<Accordion>
  <AccordionItem>
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionContent>
      Yes. It adheres to the WAI-ARIA Accordion pattern.
    </AccordionContent>
  </AccordionItem>
</Accordion>;
```

### Open Multiple

Set `openMultiple` on the root to allow multiple items to be expanded simultaneously.

<ExampleContainer>
  <Accordion openMultiple className="w-full max-w-md">
    <AccordionItem value="item-1">
      <AccordionTrigger>First section</AccordionTrigger>
      <AccordionContent>
        This panel can stay open while others are expanded.
      </AccordionContent>
    </AccordionItem>
    <AccordionItem value="item-2">
      <AccordionTrigger>Second section</AccordionTrigger>
      <AccordionContent>Try opening both at the same time.</AccordionContent>
    </AccordionItem>
    <AccordionItem value="item-3">
      <AccordionTrigger>Third section</AccordionTrigger>
      <AccordionContent>All three can be open together.</AccordionContent>
    </AccordionItem>
  </Accordion>
</ExampleContainer>

```tsx
<Accordion openMultiple>
  <AccordionItem value="item-1">
    <AccordionTrigger>First section</AccordionTrigger>
    <AccordionContent>Content</AccordionContent>
  </AccordionItem>
  <AccordionItem value="item-2">
    <AccordionTrigger>Second section</AccordionTrigger>
    <AccordionContent>Content</AccordionContent>
  </AccordionItem>
</Accordion>
```

### Default Open

Use `defaultValue` to specify which items are open initially.

<ExampleContainer>
  <Accordion defaultValue={[1]} className="w-full max-w-md">
    <AccordionItem value={0}>
      <AccordionTrigger>Collapsed by default</AccordionTrigger>
      <AccordionContent>This item starts closed.</AccordionContent>
    </AccordionItem>
    <AccordionItem value={1}>
      <AccordionTrigger>Open by default</AccordionTrigger>
      <AccordionContent>
        This item starts expanded because its value is in the defaultValue
        array.
      </AccordionContent>
    </AccordionItem>
  </Accordion>
</ExampleContainer>

```tsx
<Accordion defaultValue={[1]}>
  <AccordionItem value={0}>
    <AccordionTrigger>Collapsed by default</AccordionTrigger>
    <AccordionContent>This item starts closed.</AccordionContent>
  </AccordionItem>
  <AccordionItem value={1}>
    <AccordionTrigger>Open by default</AccordionTrigger>
    <AccordionContent>This item starts expanded.</AccordionContent>
  </AccordionItem>
</Accordion>
```

## Components

### Accordion

The root container. Wraps all accordion items.

| Prop            | Type                        | Default | Description                       |
| --------------- | --------------------------- | ------- | --------------------------------- |
| `defaultValue`  | `number[]`                  | `[]`    | Initially open item values        |
| `value`         | `number[]`                  | —       | Controlled open item values       |
| `onValueChange` | `(value: number[]) => void` | —       | Callback when open items change   |
| `openMultiple`  | `boolean`                   | `false` | Allow multiple items open at once |
| `className`     | `string`                    | —       | Additional CSS classes            |

### AccordionItem

Wraps a single trigger + panel pair.

| Prop        | Type               | Default | Description                    |
| ----------- | ------------------ | ------- | ------------------------------ |
| `value`     | `string \| number` | —       | Unique identifier for the item |
| `disabled`  | `boolean`          | `false` | Prevent opening this item      |
| `className` | `string`           | —       | Additional CSS classes         |

### AccordionTrigger

The clickable heading that toggles the panel. Renders a chevron indicator that rotates on open.

| Prop        | Type        | Default | Description            |
| ----------- | ----------- | ------- | ---------------------- |
| `children`  | `ReactNode` | —       | Trigger label content  |
| `className` | `string`    | —       | Additional CSS classes |

### AccordionContent

The collapsible content area.

| Prop        | Type        | Default | Description            |
| ----------- | ----------- | ------- | ---------------------- |
| `children`  | `ReactNode` | —       | Panel content          |
| `className` | `string`    | —       | Additional CSS classes |
